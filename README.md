\# OCaml Report Checker



OCamlのレポート課題用チェッカーです。



`.ml` ファイルをアップロードすると、課題の各実行例が正しく動作するかを確認できます。



\## できること



\- `.ml` ファイルをアップロードしてチェック

\- 複数ファイルをまとめてチェック

\- 大問ごとに OK / NG を表示

\- 詳細な小テスト結果も確認

\- コマンドラインでも実行可能



\## 必要なもの



以下が使える環境が必要です。



\- Python 3

\- OCaml



確認方法:



```bash

python3 --version

ocaml -version
