# Report Checker

レポート課題用チェッカーです。

`.ml` ファイルをアップロードすると、課題の実行例に対して自動でチェックを行い、各大問ごとに OK / NG を確認できます。

> [!WARNING]
> 使用する前に、必ず最新版に更新してから実行してください。
